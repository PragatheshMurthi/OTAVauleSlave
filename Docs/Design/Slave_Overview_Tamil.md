# இயக்க முனை மென்பொருள் பாய்வு விளக்கப்படம் (Subordinate Node Firmware Flow Diagram)

இந்த ஆவணம் முதன்மை முனையிலிருந்து (Master Node) கட்டளைகளைப் பெற்றுச் செயல்படும் துணைக்கருவி அல்லது இயக்க முனையின் (Subordinate/Actuator Node) மென்பொருள் பாய்வு கட்டமைப்பை விவரிக்கிறது.

```mermaid

    subgraph Central_Station["மத்திய முதன்மை கட்டுப்பாட்டு நிலையம்"]

        MN -->|SPI பஸ் இணைப்பு| LoRaM[முதன்மை லோராவ் டிரான்சீவர்]

        Relay -->|மின்சார விநியோகம்| Valve[நீர் / திரவக் கட்டுப்பாட்டு வால்வு]
```

## 1. பொதுவான பாய்வு மேலோட்டம் (Flow Overview)

இயக்க முனையின் முதன்மைச் சுழற்சி (Main Loop) செயல்பாட்டைக் காட்டும் பொதுவான வரைபடம்.

```mermaid
flowchart TD
    A[சுழற்சி தொடக்கம்]
    B[கட்டளையை எதிர்பார்த்தல்]
    C[கட்டளையைப் பகுப்பாய்வு செய்தல்]
    D[கட்டளையைச் செயல்படுத்துதல்]
    E[முதன்மை முனையைப் புதுப்பித்தல்]

    A --> B
    B --> C
    C --> D
    D --> E
    E -->|அடுத்த கட்டளை| B
```

---

## 2. கட்டளையை எதிர்பார்த்தல் மேலோட்டம் (Expect Order Overview)

உள்வரும் தரவு பாக்கெட்டுகளைப் பெற்று, அவற்றின் நம்பகத்தன்மை மற்றும் முழுமையைச் சரிபார்க்கும் செயல்முறை.

```mermaid
flowchart TD
    A[கட்டளை எதிர்பார்ப்புத் தொடக்கம்]
    B[கட்டளைக்காகக் காத்திருத்தல்]
    C[கட்டளையின் முழுமையை மதிப்பிடுதல்]
    D[கட்டளை ஏற்பு அறிவிப்பு]
    E[பிழையை அமைத்தல்]
    F[கட்டளை செயலாக்கப்பட்டது]

    A --> B
    B --> G{வெற்றிகரமானதா?}
    G -->|ஆம்| C
    G -->|இல்லை| E
    C --> H{வெற்றிகரமானதா?} 
    H -->|ஆம்| D
    H -->|இல்லை| E
    D --> I{வெற்றிகரமானதா?}
    I -->|ஆம்| F
    I -->|இல்லை| E
```

## 3. கட்டளையைப் பகுப்பாய்வு செய்தல் மேலோட்டம் (Parse Order Overview)

பெறப்பட்ட தரவுக் கட்டளையிலிருந்து அளவுருக்களைப் பிரித்தெடுத்து, அவை கணினியால் ஏற்றுக்கொள்ளக்கூடிய எல்லைக்குள் உள்ளதா எனச் சரிபார்க்கும் முறை.

```mermaid
flowchart TD
    A[பகுப்பாய்வுத் தொடக்கம்]
    B{பிழை உள்ளதா?}
    C[கோரிக்கையைப் பகுப்பாய்வு செய்தல்]
    D{பகுப்பாய்வு வெற்றியா?}
    E[கோரிக்கையைச் சரிபார்த்தல்]
    F{மதிப்புகள் ஏற்கத்தக்கவையா?}
    G[பொதுவான தகவல்களைப் புதுப்பித்தல்]
    H[பிழையை அமைத்தல்]
    I[கட்டளை செயலாக்கப்பட்டது]

    A --> B
    B -->|இல்லை| C
    B -->|ஆம்| H
    C --> D 
    D -->|ஆம்| E
    D -->|இல்லை| H
    E --> F{வெற்றிகரமானதா?}
    F -->|ஆம்| G
    F -->|இல்லை| H
    G --> I
```

## 4. கட்டளையைச் செயல்படுத்துதல் மேலோட்டம் (Apply Order Overview)

சரிபார்க்கப்பட்ட மதிப்புகளை அடிப்படையாகக் கொண்டு வால்வுகளை இயக்குதல் மற்றும் நேரக்கணிப்பான்களை (Timers) அமைக்கும் பகுதி.

```mermaid
flowchart TD
    A[செயல்படுத்தல் தொடக்கம்]
    B{பிழை உள்ளதா?}
    C{மதிப்பு புதியதா?}
    D[வால்வுகளை இயக்குதல்]
    E{இயக்கம் வெற்றியடைந்ததா?}
    F[உள் கட்டமைப்பைப் புதுப்பித்தல்]
    G{நேரக்கணிப்பான் புதுப்பிப்பு தேவையா?}
    H[நேரக்கணிப்பானைத் தொடங்கு/மீட்டமை]
    I{புதுப்பிப்பு வெற்றியடைந்ததா?}
    J[மதிப்புகள் பயன்படுத்தப்பட்டன]
    K[பிழையை அமைத்தல்]

    A --> B
    B -->|இல்லை| C
    C -->|ஆம்| D 
    D --> E
    E -->|ஆம்| F
    E -->|இல்லை| K
    B -->|ஆம்| K
    F --> G
    C -->|இல்லை| G
    G -->|ஆம்| H
    H --> I
    I -->|ஆம்| J
    I -->|இல்லை| K
    G --->|இல்லை| J
```

## 5. முதன்மை முனையைப் புதுப்பித்தல் மேலோட்டம் (Update Master Overview)

செயல்பாட்டின் இறுதி நிலையை (வெற்றி அல்லது தோல்வி விவரங்களுடன்) முதன்மை முனைக்குத் தகவல் பாக்கெட்டாகத் திருப்பி அனுப்பும் முறை.

```mermaid
flowchart TD
    A[முதன்மை முனை புதுப்பிப்புத் தொடக்கம்]
    B{பிழை உள்ளதா?}
    C[பிழை விளக்கம் மற்றும் குறிப்பை எடுத்தல்]
    D[வெற்றி விளக்கத்தைச் சேர்த்தல்]
    E[தற்போதைய நிலை மற்றும் செயல்பாட்டு முடிவுடன் தரவுக் கட்டமைப்பை உருவாக்குதல்]
    F[முதன்மை முனைக்கு அனுப்புதல்]
    G{அனுப்புதல் வெற்றியடைந்ததா?}
    H[தோல்வி எண்ணிக்கையை அமைத்தல்]
    I[நிலையைப் பதிவேடு செய்தல்]
    J[பிழையை நீக்குதல்]
    K[முடிவு]

    A --> B
    B -->|ஆம்| C
    C --> E
    B -->|இல்லை| D
    D --> E
    E --> F
    F --> G
    G -->|ஆம்| J
    J --> K
    G -->|இல்லை| H
    H --> I
    I --> J
```
